# shikaku-site

Страницы для сторов игры Shikaku. Публикуются через GitHub Pages.

- `/privacy/` — политика конфиденциальности. **Не редактируется здесь.**
  Исходник живёт в основном репозитории (`anuarars/shikaku`,
  `store/privacy/*.md`), страница собирается из него:

  ```
  dart run tool/render_privacy.dart <путь к этому репозиторию>/privacy
  ```

  Правка прямо здесь разойдётся с исходником — и разойдётся молча.

Корень оставлен под будущую страницу игры.
