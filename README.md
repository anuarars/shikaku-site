# shikaku-site

Сайт игры Kakomi. Отдаётся GitHub Pages. `shikaku` в имени — тип
головоломки и имя пакета, оставшееся с начала проекта.

Сейчас здесь одна страница — политика конфиденциальности, в корне:
`https://anuarars.github.io/shikaku-site/`.

**Адрес не менять.** На него ведёт пункт «Политика конфиденциальности» в
настройках приложения, а адрес зашит в сборку, и он же стоит в консолях
сторов. GitHub Pages со старого адреса не перенаправляет: переименуете
репозиторий — ссылка во всех вышедших версиях перестанет открываться.

**Здесь её не редактируют.** Исходник живёт в основном репозитории
(`anuarars/shikaku`, `store/privacy/*.md`), страница собирается из него:

```
dart run tool/render_privacy.dart <путь к этому репозиторию>
```

Правка прямо здесь разойдётся с исходником — и разойдётся молча.
